# Encore v0.6.1 — Startup & Tray Fixes

A patch release focused on starting the background recorder reliably at login.

## Fixes

- Windows login startup now stores a standard, quoted executable path. Opening
  Encore refreshes enabled startup registrations from earlier builds.
- The Windows tray icon retries if Explorer is not ready during login and returns
  when Explorer restarts. Recorder status and tray controls remain available
  without opening the library.
- Login startup reports a missing recorder helper instead of registering the
  library window as a fallback.
- On macOS, login startup opens Encore Recorder through LaunchServices, matching
  manual launch and keeping capture permissions associated with Encore Recorder.

## Install or update

**Windows:** use **Settings → App updates** in Encore 0.5.0 or later, or run
`Encore_0.6.1_x64-setup.exe`. Open Encore once after updating so an enabled
startup registration can be refreshed. Enable **Start Recorder with Windows**
and save Settings if it is currently off. Windows Startup Apps must also allow
Encore Recorder. Saved clips, library data and settings are preserved.

**macOS:** quit Encore and its recorder, open `Encore_0.6.1_aarch64.dmg` and
replace Encore in Applications. Enable **Start Recorder at login** and save
Settings to refresh the login agent. Allow the background item in System Settings
if requested. Capture permissions still belong to **Encore Recorder**.

The macOS package remains ad-hoc signed, without Apple Developer ID signing or
notarization. macOS may require **Privacy & Security → Open Anyway** after the
first launch attempt, and capture permissions may need to be granted again after
replacement. macOS updates use manual installation.

Startup starts the recorder in the tray/menu bar after signing in; it does not
open the library or start recording before login. Real Windows and macOS login
acceptance tests remain pending; automated checks cover startup path generation,
Windows tray recovery and macOS LaunchAgent content.

`latest.json` and the Windows `.sig` support signed Windows updates.
`SHA256SUMS.txt` verifies the attached files. Ubuntu and Flatpak remain available
as [manually published development previews](../cross-platform.md#publish-a-development-preview-manually).
