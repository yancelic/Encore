# Encore v0.7.0 — Screen Capture & UI Improvements

## Windows recording

- Screen capture replaces Active Window mode and records the entire primary
  display. Switching apps, opening Encore and Alt+Tab preserve replay history.
  Existing Windows Active Window settings load as Screen capture automatically.
- Screen capture includes all visible apps and notifications on the primary
  display. Game Detection continues to capture only the selected game's window.
- In application audio mode, Screen capture records the default playback device
  on the Game track. Chat remains a separate application track and may also be
  audible in the system audio. Device routing and microphone settings are preserved.
- The first saved clip now appears in the library when saving finishes, including
  hotkey saves and saves that finish after the initial library refresh.

## Interface

- Dismissing the library introduction is remembered across reopening and reloads.
- Interface text and images no longer select or drag accidentally; text fields
  remain editable.
- Recorder controls keep their size while starting and stopping. Ready status
  has clearer colors in both light and dark themes.

## macOS updates

- Stable Apple Silicon builds use the same persistent self-signed certificate
  between releases, keeping recorder privacy permissions across subsequent updates.
- Signed in-app updates now support macOS as well as Windows. Updates verify the
  package before stopping recording and wait for accepted saves and exports.
- Install this release manually when upgrading from macOS 0.6.1 or earlier, then
  grant Encore Recorder's permissions again. These older builds were ad-hoc signed.
  The certificate is not an Apple Developer ID, and the app is not notarized;
  first installation may require **Privacy & Security → Open Anyway**.

## Install

**Windows:** use **Settings → App updates** or run `Encore_0.7.0_x64-setup.exe`.

**macOS:** quit Encore and its recorder, open `Encore_0.7.0_aarch64.dmg` and replace
Encore in Applications. Open Settings → Permissions and allow Encore Recorder.

Saved clips and existing library settings are preserved. Ubuntu and Flatpak
remain experimental; this stable release contains Windows x64 and macOS
Apple Silicon packages. `latest.json` describes signed update packages, and
`SHA256SUMS.txt` covers the attached release assets.
