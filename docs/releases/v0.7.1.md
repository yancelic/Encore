# Encore v0.7.1 — Settings & UI fixes

- Selecting Screen capture now shows the correct capture-mode notification.
- The toolbar now shows the clips folder, refresh, current clip settings and
  Settings in that order. The extra shortcut button has been removed.
- Dropdown options use readable backgrounds and text in dark and light themes.
- Settings opens with replay length, save shortcut and video quality. Recording,
  Audio and General tabs make related options easier to find.
- Replay length, resolution, frame rate and capture mode use visible choices
  instead of dropdowns. Existing settings and custom replay lengths are preserved.

Update through **Settings → General → App updates**, or download the installer
for your platform. Saved clips and library settings are preserved.

macOS builds use the same persistent release certificate as 0.7.0. The app is
not notarized; first manual installation may require **Privacy & Security →
Open Anyway**. Ubuntu and Flatpak remain experimental.
