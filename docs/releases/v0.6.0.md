# Encore v0.6.0 — macOS Stable & Playback Fixes

Encore is now available as a stable release for **Windows 10/11 x64** and
**macOS 15+ on Apple Silicon**. Ubuntu and Flatpak remain beta previews.

## What's new

- macOS recording, separate audio tracks, background recorder controls and
  permissions setup are now included in the stable release.
- The editor plays all audio tracks from one Web Audio clock, improving
  synchronization when playing, seeking and resuming multi-track clips.
- Quiet audio is easier to see in the editor's decibel-scaled waveforms.
- macOS clip exports prefer Apple's VideoToolbox H.264 encoder, with software
  fallback. Audio-device discovery and recorder permission handling are fixed.
- Windows receives the shared editor playback and waveform improvements while
  retaining signed in-app updates.

## Install or update

**Windows:** download `Encore_0.6.0_x64-setup.exe`, or use **Settings → App
updates** in Encore 0.5.0. Users on 0.4.0 or earlier should install manually.
Saved clips, library data and settings remain outside the installation directory.

**macOS:** download `Encore_0.6.0_aarch64.dmg`, open it and drag Encore into
Applications. Quit the previous Encore and its background recorder before
replacing an existing installation. Open **Settings → Permissions** and grant
Screen & System Audio Recording, Microphone and Input Monitoring to **Encore
Recorder** as requested. macOS updates currently use manual installation.

The macOS package uses ad-hoc code signing. It is **not Apple Developer ID signed
or notarized**; macOS may require approval in **System Settings → Privacy &
Security → Open Anyway** after the first launch attempt. A replacement build may
require granting recorder permissions again. If older permission entries interfere,
use Encore's **Reset permissions**, then grant them again.

`latest.json` and the Windows `.sig` support signed Windows updates.
`SHA256SUMS.txt` verifies the attached files. Linux beta packages remain available
from the [beta release](https://github.com/yancelic/Encore/releases/tag/beta).
